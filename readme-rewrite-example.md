## After

    # Weather App

    A simple command-line app that shows the current weather for any city.

    ## Requirements

    - Node.js 18 or later
    - A free API key from OpenWeatherMap

    ## Setup

    1. Clone the repo and install dependencies: `npm install`
    2. Create a `.env` file and add your key: `API_KEY=your_key_here`
    3. Start the app: `npm start`

    ## Usage

    Run `npm start`, then type a city name when prompted.
